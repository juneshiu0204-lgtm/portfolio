# Everyday News Skill

每日新闻日报自动化生成与推送技能。

## 功能概述

- 获取北京市西城区当日天气信息
- 采集四个行业的最新资讯（每行业 5 篇）：
  - 科技：36氪、虎嗅、少数派
  - AI：机器之心、新智元、量子位
  - 金融：财新网、华尔街见闻、东方财富
  - 商业：第一财经、界面新闻、商业周刊中文版
- 生成 Markdown 格式日报，保存至 `./新闻日报/YYYY-MM-DD.md`
- 通过飞书 API 分两段推送到指定群聊

## 触发方式

- 手动触发：用户指令包含"每日新闻"、"新闻日报"、"推送新闻"等关键词

## 执行步骤

1. **获取天气信息**：通过 Open-Meteo API（集成 weather skill）获取北京市西城区今日天气，无需 API key
2. **采集行业资讯**：使用 web_search 分别搜索四个行业的最新新闻
3. **筛选新闻**：每个行业筛选 5 篇最新文章，确保每篇包含标题、概要、链接
4. **生成日报**：按照指定格式生成 Markdown 文件，保存到 `./新闻日报/YYYY-MM-DD.md`
5. **推送飞书**：通过飞书 API 分两段发送消息到群聊
   - 第一段：天气 + 科技 + AI
   - 第二段：金融 + 商业 + MD 文件链接

## 新闻格式要求

每条新闻必须包含三要素：
```plaintext
1️⃣ 标题
概要（一句话概括新闻核心内容，不超过50字）
xxx（链接）
```


## 注意事项

1. 确保网络连接正常，能够访问新闻网站和飞书 API
2. 每篇新闻的概要需要准确概括，不超过 50 字
3. 推送时分两段发送，避免单条消息过长
4. 日报文件需要按日期命名，确保历史可追溯
