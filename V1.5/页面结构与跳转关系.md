## 三、页面跳转关系

### 3.1 主流程跳转

```
首页 (index.html) - 默认打开【服务管理】- 空间服务管理列表
  │
  ├─→ 数据汇聚
  │    ├─→ 汇聚任务列表 → 新增/编辑汇聚任务 (弹窗)
  │    └─→ 文件上传 → 上传完成 → 数据管理
  │
  ├─→ 数据管理
  │    ├─→ 目录树选择目录 → 右侧数据列表 → 点击数据 → 数据详情页
  │    └─→ 数据详情页 → 编辑 / 删除 / 发布服务 / 处理
  │
  ├─→ 数据查询
  │    └─→ 输入条件查询 → 结果列表 → 点击跳转数据详情
  │
  ├─→ 数据处理
  │    ├─→ 选择处理类型 → 选择输入数据 → 设置参数 → 执行处理 → 生成结果
  │    └─→ 处理结果 → 可跳转新数据详情
  │
  ├─→ 服务管理
  │    ├─→ 服务列表 → 查看服务地址 / 编辑 / 停止
  │    └─→ 服务组管理 → 添加移除服务 → 排序调整
  │
  ├─→ 数据可视化
  │    └─→ 选择图层/服务 → 在地图中展示
  │
  └─→ 系统管理
       ├─→ 配置管理 → 保存配置
       └─→ 操作审计 → 查看审计详情
```

### 3.2 跳转规则

1. **顶部导航**：点击任何一级菜单，切换主内容区域，侧边栏跟着变化
2. **侧边栏二级菜单**：点击菜单项，切换右侧主内容对应的页面
3. **列表页 → 详情页**：点击列表项或"查看"按钮，跳转到详情页
4. **详情页 → 编辑页**：点击"编辑"按钮，跳转到编辑页（或弹窗编辑）
5. **编辑/新增 → 列表**：保存成功后，返回列表页
6. **数据详情 → 发布服务**：点击"发布"按钮，跳转到服务管理发布页面
7. **数据详情 → 数据处理**：点击"处理"按钮，跳转到对应数据处理页面并自动填充选中数据

### 3.3 面包屑导航（可选）

每个页面应该展示面包屑：
```
首页 > 数据管理 > TIF数据 > 数据详情
```

## 五、公共组件

- **搜索表单**：条件搜索区域
- **目录树组件**：数据目录树形展示
