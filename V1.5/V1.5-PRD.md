## 1. 产品概述

### 1.1 文档目的

本文档详细描述行业通用软件V1.5版本的空间分析相关功能需求，包括缓冲区分析、叠加分析、空间插值、数据拼接与镶嵌、数据查询与检索、数据汇聚归类打标规则、矢量瓦片服务、MBTiles多文件支持、点云数据格式支持、矢量引擎（地图配图工作台）、栅格SLD样式管理、发布四维地球日新图服务、时序影像服务、S3云存储支持等核心功能。
  
### 1.2 术语定义

- **缓冲区分析**：围绕点、线、面要素生成一定距离内的影响区域
- **叠加分析**：对两个或多个图层进行空间运算，生成新的空间要素
- **空间插值**：根据已知点的属性值，推测未知点属性值的方法
- **数据拼接**：将多幅相邻或重叠的影像简单地拼接在一起
- **数据镶嵌**：在拼接的基础上进行更高级的处理，包括镶嵌线提取和色彩平衡
- **矢量瓦片**：将矢量数据按瓦片组织的高效数据传输格式
- **MBTiles**：基于SQLite的瓦片存储格式，用于存储和分发地图瓦片
- **点云数据**：由大量三维坐标点组成的数据，通常来自激光雷达或摄影测量
- **COG**：Cloud Optimized GeoTIFF，一种优化的栅格数据格式，支持高效的云存储访问
- **3D Tiles**：一种用于流式传输和渲染大规模三维地理数据的格式
- **SLD**：Styled Layer Descriptor，一种用于定义地图图层样式的XML格式
- **日新图**：四维地球每日更新的卫星影像产品
- **时序影像服务**：将同一区域、不同时间的多景影像组织为一个服务，供客户端按时间轴切换查看的服务
- **S3**：Simple Storage Service，一种对象存储服务，提供高可扩展性、安全性和性能
- **对象存储**：一种数据存储架构，将数据作为对象存储，每个对象包含数据、元数据和唯一标识符
- **STAC**：SpatioTemporal Asset Catalog，一种用于描述地球观测数据的规范

## 2. 功能模块
### 2.1 【服务发布】时序影像服务

#### 2.1.1 功能背景

时序影像服务是将同一区域、不同时间的多景影像组织为一个服务，供客户端按时间轴切换查看，用于土地变化监测、工程进度跟踪、灾害前后对比等场景。

#### 2.1.2 功能描述   

- **服务图层管理**：在服务组详情页新增"服务图层管理"模块，支持对已添加的服务图层进行统一管理
- **排序功能**：支持两种排序方式（单选）：
  - **自定义排序**：用户在编辑态通过拖拽手柄手动调整服务图层顺序
  - **按数据获取时间排序**：系统自动从各服务元数据读取数据获取时间，按时间升序排列，无需用户手动填写
- **编辑态/查看态**：模块默认为查看态（只读），点击"编辑"按钮进入编辑态；编辑态支持调整排序方式、拖拽排序、添加/移除服务图层；点击"确认"提交变更，点击"取消"回滚至编辑前状态
- **服务图层列表**：展示已添加服务的名称、原始数据格式、网格集、层级、缩略图、资产标签、数据获取时间
- **自动时间提取**：从服务元数据自动读取数据获取时间，在列表中展示，无需用户手动填写
- **时间轴接口**：在数据可视化模块，提供按时间排序的服务列表接口，供前端时间滑块使用
- **时间滑块交互**：客户端支持按时间轴切换不同时相的影像
- **时序播放控制**：在数据可视化模块提供时序播放条，支持自动播放和手动切换服务图层

#### 2.1.3 交互方式

1. **服务组管理**：
   - 用户进入服务组详情页，默认展示查看态：排序方式单选（置灰只读）、移除/添加服务按钮（置灰禁用）、服务图层列表（checkbox 置灰禁用）
   - 点击右上角"编辑"按钮，进入编辑态，"编辑"按钮切换为"取消"和"确认"
   - 编辑态下：
     - 排序方式单选激活，可切换"自定义排序"或"按数据获取时间排序"
     - 选择"自定义排序"时，列表左侧显示拖拽手柄，用户可拖拽调整图层顺序；切换为"按数据获取时间排序"时，系统自动按数据获取时间升序重排，拖拽手柄隐藏
     - 勾选服务图层后，"移除"按钮激活，可移除选中图层
     - 点击"添加服务"按钮，弹出服务选择弹窗，可查询并勾选服务后确认添加
   - 点击"确认"提交当前排序方式和图层顺序；点击"取消"回滚至进入编辑前的状态

2. **时序影像播放**：
   - 发布服务组后，在数据可视化模块的图层中加载服务组
   - 点击右侧工具栏"时序"按钮，底部弹出时序播放条
   - 点击播放条左上角"选择服务组"按钮，弹出服务组选择弹窗
   - 弹窗中支持按服务名称、资产标签查询，仅显示"按数据获取时间排序"的服务组（单选）
   - 选中服务组后点击"确认"，播放条显示"当前服务组：XXX"
   - 播放控制区包含：
     - 上一个节点（⏮）：跳转到上一个时间节点
     - 开始/暂停（▶/⏸）：自动播放或暂停播放
     - 下一个节点（⏭）：跳转到下一个时间节点
     - 时间轴滑块：可拖动选择任意时间节点
     - 进度指示器：显示当前进度（如 1/7）
     - 间隔设置：数字输入框，默认2秒，可设置1-60秒
   - 播放到最后一个节点后自动循环到第一个节点
   - 点击播放条右上角"×"按钮，关闭时序播放功能

#### 2.1.4 逻辑流程

1. 各期影像分别发布为独立 WMTS 服务
2. 进入服务组详情 → 点击"编辑" → 添加服务图层 → 选择排序方式（自定义拖拽 或 按数据获取时间）→ 点击"确认"保存
3. 系统从各服务元数据读取数据获取时间，在列表"数据获取时间"列展示，按时间排序时自动升序重排
4. 在数据可视化模块，提供按时间排序的服务列表接口，供前端时间滑块使用
5. 开启"时序"功能 → 选择服务组 → 时间轴滑块展开，客户端按时间轴切换不同时相的影像
6. 支持自动播放（按设定间隔循环播放）和手动切换（点击节点或拖动滑块）

### 2.2【数据查询】数据查询与检索功能

#### 2.2.1 功能背景

数据查询与检索是用户获取和使用空间数据的基础功能，支持用户快速定位和获取所需数据。

#### 2.2.2 功能描述

- **检索结果导出/下载**：支持将查询结果导出为多种格式，包括矢量格式（Shapefile、GeoJSON、KML、CSV）、栅格格式（GeoTIFF、IMG）、瓦片格式（MBTiles、XYZ Tiles）
- **检索历史记录保存和回溯**：保存用户的查询历史记录，支持查询条件保存、查询结果缓存、历史记录回溯、收藏常用查询

#### 2.2.3 交互方式

1. **导出功能**：用户执行查询后，点击"导出"按钮，选择导出格式和参数，完成导出
2. **历史记录**：用户可在"历史记录"面板查看过去的查询记录，点击记录可重新执行查询，可标记常用查询为收藏

#### 2.2.4 逻辑流程

1. **导出流程**：用户执行查询 → 系统生成查询结果 → 用户选择导出格式 → 系统执行导出 → 下载文件
2. **历史记录流程**：用户执行查询 → 系统保存查询条件和结果 → 用户查看历史记录 → 选择历史记录 → 系统重新执行查询

#### 2.3.2 shp/geojson数据汇聚到pg

**功能概述**：
用于定时汇聚指定目录下的 Shapefile 或 GeoJSON 数据，并可选入库到 PostgreSQL/PostGIS 数据库。

**表单区域**：

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 任务名称 | 输入框 | ✅ | 汇聚任务名称 |
| 入库数据类型 | Tab切换 | ✅ | 以单个文件入库 / 以数据集形式入库 |

| 物理数据位置 | 按钮 | ✅ | 选择数据所在目录 |
| 入库数据目录 | 下拉框 | ✅ | 选择入库目标目录 |
| 检测格式 | 多选框组 | - | 选择需要检测的数据格式，包含栅格、矢量、三维模型、瓦片、三维瓦片 |
| 入库目标 | - | - |  |
| 入库到PostGIS库（新增） | 复选框 | - | 默认勾选，勾选后入库不保存原始文件。只有当检测格式勾选了 Shapefile 或 GeoJSON 时，"入库到PostGIS库"才可用 |
| 数据库（新增） | 下拉框 | ✅（勾选时）| 选择目标数据库 |
| Schema（新增） | 下拉框 | ✅（勾选时）| 选择目标Schema |

   - 仅作为文件存储

4. 勾选需要检测的数据格式

6. 勾选入库到PostGIS库时填写数据库和Schema信息

8. 点击"确认"创建汇聚任务

#### 2.3.4 pg下载为csv/shapefile/geojson格式的文件

##### 2.3.4.1 页面概述

用于将 PostgreSQL/PostGIS 中的矢量数据导出为 CSV、Shapefile 或 GeoJSON 格式文件。

**页面位置**：数据管理 → 数据下载 → 创建下载任务

**表单区域**：

| 字段名 | 类型 | 必填 | 编辑权限 | 说明 |
|--------|------|------|----------|------|
| 数据名称 | 输入框 | ✅ | ✗ 只读（置灰）| 由前端带入，不可修改 |
| 导出格式 | 单选按钮组 | ✅ | ✓ 可选 | 三选一 |

**导出格式选项**：

| 格式 | 默认值 | 说明 |
|------|--------|------|
| CSV | - | 逗号分隔值文件，不含几何信息或几何以 WKT 形式存储 |
| Shapefile | ✓ 默认选中 | ESRI Shapefile 标准格式，包含 .shp/.shx/.dbf/.prj 多文件 |
| GeoJSON | - | 基于 JSON 的开放地理空间数据交换格式 |

**底部操作按钮**：
- **确认**：执行导出操作
- **取消**：返回上一页

##### 2.3.4.2 业务规则

1. **数据来源**：数据名称由列表页点击某条记录时自动带入，用户不可修改
2. **格式选择**：必须选择一种导出格式，默认选中 Shapefile
3. **导出限制**：
   - CSV 格式：仅支持属性数据导出
   - Shapefile 格式：自动生成配套的4个文件（.shp/.shx/.dbf/.prj）
   - GeoJSON 格式：输出单个 .geojson 文件，包含完整几何和属性信息
4. **坐标系**：直接使用数据源原始坐标系
5. **编码设置**：默认使用数据源原始编码


##### 2.3.4.3 交互逻辑

1. 用户在数据列表页选择某条 PostGIS 数据记录
2. 点击"导出"或"下载"操作进入本页面
3. 页面自动填入**数据名称**（只读）
4. 用户选择**导出格式**
5. 点击"确认"触发导出任务
6. 导出完成后提供文件下载链接或直接下载

#### 2.3.5 PG数据详情/编辑页面

#### 2.3.6 PG发布矢量瓦片服务(MVT)页面

##### 2.3.1.1 MVT
矢量瓦片是一种高效的数据传输格式，将矢量数据按瓦片组织，支持大规模矢量数据的快速可视化和自定义样式渲染。

MVT (Mapbox Vector Tile) 是一种 服务格式 ，而非服务协议。
- 对应的服务协议：WMTS、TMS、Google XYZ
- 服务格式：MVT、PBF

Mapbox标准地址格式：https://{host}/{path}/{z}/{x}/{y}.pbf
- {z} (Zoom)： 缩放层级（通常为 0-22）
- {x} (Column)： 瓦片的列号
- {y} (Row)： 瓦片的行号
- 文件后缀：.pbf （或 .mvt，可以先不支持）

根据协议URL组织方式不同：
- Google XYZ：/service/road/{z}/{x}/{y}.pbf
- TMS：/service/road/{z}/{x}/{-y}.pbf
- WMTS：/service/road/wmts?request=GetTile&...

#### 2.3.2 页面描述
填写以下参数，用于发布服务：
- 服务名称：必填，string
- 资产标签：非必填，单行文本框
（分隔符）
- 数据表名：前端带入自动填写，置灰，不允许修改
- 空间几何字段：必填，下拉框单选，前端带入自动填写，置灰，不允许修改
- 发布属性字段：必填，下拉框多选
- 发布协议-发布格式：发布协议WMTS、TMS、Google XYZ，发布格式为MVT (pbf)，仅单选
（分隔符）
- 网格集：必填，下拉框单选，目前仅支持3857，默认值3857
- 层级信息：必填，默认值10至18

### 2.4 【数据管理】S3云存储支持

#### 2.4.1 功能背景

对于K8S版本，目前用户没有将数据上传的服务器的途径，因此通过对接云存储（腾讯云COS、华为云OBS、阿里云OSS、MinIO等），用户通过cos客户端将数据上传到云存储中，再通过系统从云存储中汇聚数据，实现数据的无缝访问和管理。

#### 2.4.2 功能描述

- **S3云存储数据源管理**：支持添加、编辑、删除S3云存储数据源，配置连接参数
- **数据汇聚与入库**：支持从S3云存储自动同步数据，提取元数据，构建索引
- **数据管理**：支持统一浏览、查询、分类、标签管理S3中的数据
- **数据处理**：支持直接处理S3中的数据，将结果写回S3
- **服务发布**：支持将S3中的数据直接发布为标准OGC服务
- **数据迁移与备份**：支持在本地存储和S3之间进行数据迁移和备份

#### 2.4.3 交互方式

1. **数据源配置**：管理员进入数据源管理页面，添加S3云存储数据源，配置连接参数
2. **数据汇聚**：配置同步任务，系统自动从S3同步数据
3. **数据管理**：在数据管理页面浏览和管理S3中的数据
4. **数据处理**：选择S3中的数据作为输入，配置处理参数，提交处理任务
5. **服务发布**：选择S3中的数据，配置服务参数，发布为标准OGC服务
6. **数据迁移**：选择源存储和目标存储，配置迁移参数，执行迁移操作

#### 2.4.4 逻辑流程

1. **数据源配置流程**：用户配置S3数据源 → 系统验证连接 → 保存配置
2. **数据汇聚流程**：配置同步任务 → 系统定时执行 → 扫描S3存储 → 提取元数据 → 构建索引 → 入库
3. **数据处理流程**：用户选择数据和处理工具 → 配置参数 → 系统读取S3数据 → 执行处理 → 将结果写回S3
4. **服务发布流程**：用户选择S3数据 → 配置服务参数 → 系统生成服务配置 → 启动服务 → 动态生成瓦片
5. **数据迁移流程**：用户配置迁移任务 → 系统执行迁移 → 监控进度 → 完成后通知用户

### 2.5 【数据管理】三维格式转换-shp转3dtiles

#### 2.5.1 功能背景

将Shapefile格式的矢量数据转换为3D Tiles格式，主要应用于建筑面shp转3dtiles白模，实现白模数据的数据的快速发布和跨平台共享。

#### 2.5.2 功能描述

- **格式转换**：支持将Shapefile（.shp）格式的矢量数据转换为3D Tiles格式
- **参数配置**：支持配置转换参数，包括层级设置、几何简化、属性处理等
- **进度监控**：提供转换进度实时展示，支持停止任务
- **服务发布**：支持将转换结果发布为3D Tiles服务

#### 2.5.3 交互方式

1. **数据选择**：用户在数据管理页面选择Shapefile文件，点击"数据处理-三维格式转换"
2. **参数配置**：在新建任务页面，设置高度字段、LOD层级、几何简化等信息
3. **执行转换**：点击"确认"按钮，系统开始处理，显示转换进度条
4. **结果查看**：转换完成后，点击跳转查看生成的3D Tiles
5. **预览发布**：用户发布3D Tiles服务并预览

#### 2.5.4 逻辑流程

1. 用户选择Shapefile数据 → 系统解析文件结构 → 提取几何和属性信息
2. 用户配置转换参数 → 系统验证参数合法性
3. 系统执行格式转换 → 生成3D Tiles瓦片数据 → 更新进度
4. 转换完成后 → 生成3D Tiles数据 → 发布服务

### 2.7 【系统管理】系统操作审计

#### 2.7.1 功能背景

系统操作审计用于记录和追溯用户在系统中的所有操作行为，帮助管理员了解用户操作情况、定位问题、满足合规审计需求。

#### 2.7.2 功能描述

- **审计日志查询**：支持按模块、操作类型、操作租户、操作用户、操作时间范围等条件进行筛选查询
- **审计日志展示**：表格形式展示审计记录，包含操作时间、模块、子模块、操作类型、请求方式、租户ID、用户ID、IP等字段
- **审计详情查看**：用户点击"详情"按钮，弹窗展示完整的审计信息，最后显示请求体内容
- **分页浏览**：支持审计日志的分页展示
- **仅查询查看**：本模块仅支持查询和查看，不支持新增、编辑、删除操作

#### 2.7.3 交互方式

1. **进入页面**：
   - 用户点击顶部Tab导航"系统管理" → 侧边栏"操作审计"
   - 页面展示审计日志列表，默认显示全部数据（分页）

2. **筛选查询**：
   - 用户可选择模块（下拉：数据汇聚/数据管理/数据查询/数据处理/服务管理/数据可视化/控制台）
   - 用户可选择操作类型（下拉：新增/编辑/删除/查看/下载/发布/启用/禁用）
   - 用户可输入操作租户名称进行筛选
   - 用户可输入操作用户名称进行筛选
   - 用户可选择操作时间范围（开始日期 至 结束日期）
   - 点击"搜索"按钮执行筛选查询
   - 点击"重置"按钮清空所有筛选条件，恢复默认列表

3. **查看详情**：
   - 用户点击审计日志行末尾的"详情"链接
   - 弹窗展示完整审计信息，按顺序包括：操作时间、模块、子模块、操作类型、请求方式、租户ID、用户ID、IP，最后显示请求体内容（格式化JSON展示）
   - 点击"关闭"按钮关闭弹窗

#### 2.7.4 字段说明

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 操作时间 | datetime | 操作发生的具体时间，精确到秒 |
| 模块 | string | 操作所属的功能模块：数据汇聚/数据管理/数据查询/数据处理/服务管理/数据可视化/控制台 |
| 子模块 | string | 具体操作的子模块或对象标识，如：汇聚任务、影像数据、WMTS服务、检索历史、导出任务、标签规则等 |
| 操作类型 | enum | 操作的类型：新增、编辑、删除、查看、下载、发布、启用、禁用 |
| 请求方式 | enum | HTTP请求方法：POST、PUT、GET、DELETE等，不同类型用不同颜色标签显示 |
| 租户ID | string | 执行操作的租户ID标识 |
| 用户ID | string | 执行操作用户的ID标识 |
| IP | string | 操作发起的IP地址 |
| 请求体 | string | 完整的请求参数，格式化JSON展示，仅在详情弹窗中显示 |
