# Health Skill 使用指南

健康管理与减脂追踪自动化技能。基于PCOS和脊柱侧弯病史，执行严格控糖与稳核运动。

## 📦 快速开始

### 1. 安装配置

```bash
cd /home/gem/workspace/agent/workspace/skills/health-skill
./setup.sh
```

### 2. 配置定时任务

在OpenClaw中执行：

```
openclaw cron add --name "health-daily-review" \
  --schedule "0 30 23 * * *" \
  --payload "kind: agentTurn" \
  --message "执行每日健康复盘，汇总今日饮食运动数据并生成健康日报" \
  --enabled true
```

> ⚠️ 注意：`23:30` 为UTC时间，请根据实际时区调整（中国时区=UTC+8，即北京时间23:30=UTC 15:30）

## ⚙️ 配置说明

### config.json 主要配置项

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `user_profile` | 用户基本信息 | 见文件 |
| `nutrition_quota` | 每日营养配额 | 热量1250-1350kCal |
| `exercise_quota` | 每周运动配额 | 力量3-4次，有氧3-5次 |
| `bitable` | 多维表格配置 | 日记表/日程表/食物表 |
| `workflow` | 工作流配置 | 每日复盘时间23:30 |
| `safety_rules` | 安全规则 | 控糖严格模式、禁止扭转动作 |

## 🔧 安全红线

### 饮食安全
- ❌ **绝对禁止**推荐高糖、高GI食物
- ✅ 练后餐可允许30g以内快速碳水（如香蕉、少量甜食）
- ✅ 严格控制总热量在1250-1350kCal范围内

### 运动安全
- ❌ **绝对禁止**推荐包含脊柱扭转的运动
- ❌ 禁止大负重深蹲、高强度HIIT
- ✅ 推荐死虫式、平板支撑、臀桥、鸟狗式、靠墙静蹲等脊柱友好动作

## 📝 使用示例

### 日常对话示例

**用户**：我今天中午吃了宫保鸡丁和半碗米饭
**助手**：好的，已帮你记录午餐。宫保鸡丁（约200g）+ 半碗米饭（约100g）≈ 450kCal，碳水45g，蛋白25g，脂肪20g。

**用户**：我今天还可以摄入多少卡路里？
**助手**：今日已摄入 850kCal，剩余额度约 400-500kCal（已预留100kCal容错）。建议晚餐控制在400kCal以内。

**用户**：推荐我晚上吃什么？
**助手**：建议吃一份魔芋麻辣拌（少油版），主食换成荞麦面。既满足你爱吃辣的口味，又不会引起血糖大幅波动。

**用户**：我想练腹肌，有什么推荐？
**助手**：考虑到你的脊柱侧弯，不推荐常规卷腹动作。建议练习：
1. 死虫式 - 3组×12次/侧
2. 平板支撑 - 3组×30-60秒
3. 鸟狗式 - 3组×10次/侧
这些都是脊柱友好的核心训练动作。

## 🚨 常见问题

### Q: 日报没有自动生成？
A: 请检查cron定时任务是否正确配置，确认时区设置正确。

### Q: 食物热量不准确？
A: 可以手动修正，或使用"将xx食物的热量添加到食物表中"命令更新食物数据库。

### Q: 运动记录怎么添加？
A: 直接口述运动内容即可，如"今天跑了5公里"、"晚上练了胸"，我会自动整理记录。
